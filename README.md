# TEDxCMU Website - Complete Redesign

A fully redesigned TEDxCMU website with a unified, clean aesthetic inspired by the original stories.html page. This redesign maintains all original content while providing a cohesive, professional, and modern user experience across all pages.

## ✨ Design Philosophy

The new design features:
- **Clean, editorial aesthetic** - Minimal, sophisticated layout with plenty of white space
- **Consistent typography** - Beautiful serif italics for emphasis, clean sans-serif for body
- **Professional color scheme** - Black, white, and subtle grays with the iconic TEDx red logo
- **Responsive design** - Works beautifully on desktop, tablet, and mobile
- **Smooth interactions** - Subtle hover effects and transitions throughout

## 🚀 How to Use

### Viewing the Site
1. Open `index.html` in any web browser to see the homepage
2. Navigate using the header menu to explore all pages
3. All pages are fully functional with working forms and links

### Customization
**Adding Real Photos:**
Replace gradient placeholders in `team.html` with:
```html
<div class="member-image">
    <img src="path/to/photo.jpg" alt="Member Name">
</div>
```

**Adding More Stories:**
Copy a story block in `stories.html` and modify the content

**Updating Events:**
Edit event cards in `events.html` with new information

**Newsletter Forms:**
Currently show alert on submit - connect to your email service provider
